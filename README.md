# ceo-of-agents.github.io

The landing page for [ceo-of-agents](https://github.com/ceo-of-agents/ceo-of-agents-core), a Claude Code plugin with a Mac app: a chief of staff and departments that work from one git repo you own.

## Preview locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

## How it is built

Plain HTML and CSS with a little JavaScript for the copy buttons and the clip play/pause controls. There is no build step, no package manager and no third-party requests: the page loads only its own files.
